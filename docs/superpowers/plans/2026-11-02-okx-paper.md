## Design
- New OkxMarket adapter; same symbol aliases but native instId/venue/contracts and base-coin quantities kept explicit. Contract lot/min/max converted through ctVal*ctMult. No Binance min-notional fabricated; required notional comes from native minimum contracts and current quote. Keep existing fee/slippage assumptions and per-trade allocation3–5%, BTC15/ETH10/SOL7/HYPE5.
- Only confirmed closed candles, UTC15m/1h/4h, ascending with gaps rejected. Throttle public REST calls and obey429/418backoff; no credentials/order API.
- Native trade IDs remain strings/BigInt, never assume contiguous OKX IDs. Replay one-minute proven windows, paginate backwards to coverage boundary, sort and map to local sequential replay cursor with native IDs persisted. Never approximate TP/SL using OHLC when trade history is incomplete. Bounded catch-up remains fail-closed.
- Funding history uses actual realizedRate, event-time idempotency and explicit pre-event1m mark-close proxy. Missing/malformed history or mark candle blocks accounting. Preserve estimate method, interval, source and price for every event; no claim of exact exchange debit.
- State/trades/quotes/config are labelled OKX. Refuse Binance/unknown positions at OKX boundary. New100USD state created once on paper-state-okx; never reset it in later runs. Preserve original Binance ledger and do not settle/rename its positions.
- GitHub remains sole durable writer, Render runs signed provisional cycles and serves only committed OKX view. All failed-response/publication rules remain. Only manual validation until tests+independent review+successful source-backed run, then approved cutover/schedule. Exact direct-main publication requires explicit approval after prior auto-review rejection.
